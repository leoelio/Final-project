# WidowX MuJoCo Core V2 RLDS Source v1

Private source dataset for the graduation-project Kaggle experiment.

- 79 successful scripted-expert episodes
- 2,528 synchronized image/state/action steps
- 128x128 top-camera RGB images
- Four tabletop language tasks

The archive contains `manifest.json`, `episodes/`, `images/`, and `preview_grid.png`.
It is an immutable source input for the remote semantic-adapter training run, not a public benchmark.
